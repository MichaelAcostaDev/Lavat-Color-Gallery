# 🌋 Lavat Color Patterns

A curated collection of **60 color combinations** designed for [Lavat](https://github.com/AngelJumbo/lavat), a lava lamp simulation for the Linux terminal.

This project provides a simple and visual way to explore different color combinations and find interesting palettes for your Lavat terminal setup.

## ✨ Features

* 🎨 **60 curated color combinations**
* 🌈 Visual preview for every color pattern
* 💻 Ready-to-use Lavat commands
* 🔢 HEX values displayed for each color
* 🔎 Built-in pattern search
* 📋 Click any command to copy it to the clipboard
* 📱 Responsive and lightweight design
* 🚫 No frameworks or dependencies required
* 🌐 Works directly in any modern browser

## 🎨 What's Included?

Every pattern contains:

* A unique pattern name
* A visual representation of the combination
* Two HEX colors
* The corresponding Lavat command

For example:

```bash
lavat -g -c FF3B00 -k FFB000
```

This makes it easy to go from browsing a palette to testing it directly in your terminal.

## 🖥️ Preview

The project presents all color combinations in a responsive card-based gallery.

Each card contains a visual preview similar to the kind of gradient that can be achieved with Lavat, followed by the HEX values and the command required to reproduce the combination.

## 🚀 Usage

You don't need to install anything.

Simply open:

```text
lavat-color-patterns.html
```

in your web browser.

Find a pattern you like, click its Lavat command to copy it, and paste the command into your Linux terminal.

### Example

```bash
lavat -g -c 00A86B -k 7CFC00
```

> Make sure Lavat is already installed on your linux distribution and configured on your system before using the commands.

## 🛠️ Technologies

This project was intentionally kept simple and dependency-free.

* **HTML5** — Page structure
* **CSS3** — Layout, gradients, responsive design and visual previews
* **JavaScript** — Search functionality and clipboard interaction

No build tools, packages, frameworks or external libraries are required.

## 🌋 About Lavat

This project was created as a color-pattern collection for **[Lavat](https://github.com/AngelJumbo/lavat)** by **AngelJumbo**.

Lavat is a lava lamp simulation that runs directly in the Linux terminal and supports different visual configurations, including truecolor gradients.

This repository is an independent community-made collection of color combinations and is **not affiliated with or endorsed by the Lavat project**.

All credit for Lavat itself goes to its original author and contributors.

## 🎯 Purpose

The goal of this project is to make experimenting with Lavat colors easier.

Instead of manually trying random HEX values, you can browse a collection of predefined combinations, see an approximation of the visual result, and immediately copy the corresponding command.

It can also serve as a small reference for creating your own Lavat palettes.
